# gbarecomp-keyinput-v1
# frame,keyinput_active_low
# Player-driven exploration route "explore-1": the same menu navigation as
# gameplay-right.keyinput.txt (START at 5300, A at 5800/6600/7400, RIGHT at
# 8200/8600, A at 9000/10000/11000) and then a rich in-game sequence instead of
# one held direction:
#   12000-13400  walk LEFT          (new space opens left of the start position)
#   13400-13600  LEFT + UP          (door test at the far left)
#   14000-16400  RIGHT with A jumps (pipe / ledge test on the right structure)
#   16400        DOWN tap           (pipe entry test)
#   17600-18900  LEFT, then LEFT+UP (second door test)
#   19200        UP tap
#   19600        LEFT + A           (attack an enemy while walking)
# GBA KEYINPUT is ACTIVE LOW: 0x03FF = nothing held.
#   A 0x03FE   B 0x03FD   START 0x03F7
#   RIGHT 0x03EF  LEFT 0x03DF  UP 0x03BF  DOWN 0x037F
#   RIGHT+A 0x03EE  LEFT+A 0x03DE  LEFT+UP 0x039F  UP+A 0x03BE
