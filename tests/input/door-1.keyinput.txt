# gbarecomp-keyinput-v1
# frame,keyinput_active_low
# Player-driven door route "door-1": the same menu navigation as
# gameplay-right.keyinput.txt / explore-1.keyinput.txt (START at 5300, A at
# 5800/6600/7400, RIGHT at 8200/8600, A at 9000/10000/11000), then the door
# tests done properly instead of combined with a walk:
#   12000-13500  walk LEFT                    (reach the far-left end of the room)
#   13500        release everything           (stand still, all buttons up)
#   13700        UP alone                    (door test while standing)
#   14000        UP alone                    (second clean press)
#   14300        LEFT alone                  (walk into the door structure)
#   15100        A alone                     (attack / interact)
#   15400        DOWN alone                  (pipe entry test)
#   15700        LEFT + UP                   (combo, as in explore-1)
# The raw-frame release gaps are what distinguish this route from explore-1,
# where every UP press happened while LEFT was still held.
# GBA KEYINPUT is ACTIVE LOW: 0x03FF = nothing held.
#   A 0x03FE   B 0x03FD   START 0x03F7
#   RIGHT 0x03EF  LEFT 0x03DF  UP 0x03BF  DOWN 0x037F
#   RIGHT+A 0x03EE  LEFT+A 0x03DE  LEFT+UP 0x039F  UP+A 0x03BE
